# Race Strategist for iRacing - downloads

A pit strategist for iRacing: when to box, how much fuel, wets or slicks, what to change in the car - on the radio, on an overlay over the sim and on SimHub dashboards.

**Install:** download `RaceStrategist-<version>.zip` from the [latest release](https://github.com/rodrigoblopes/race-strategist-releases/releases/latest), unzip it to a folder it can stay in (for example `Documents\RaceStrategist`), and double-click `Install.bat`. It installs Python if needed and offers SimHub and Crew Chief. Step by step: the installation PDF in the same release (also inside the zip).

**Updates:** an installed Race Strategist (1.1.0 or newer) finds new releases here and installs them by itself - never while iRacing is running.

This repository holds the release packages only.
